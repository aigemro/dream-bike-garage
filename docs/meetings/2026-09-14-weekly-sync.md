# 주간 진행 공유 — 2026-09-14

## 회의 운영

- 앞으로 정례 회의는 **매주 월요일 점심시간에 짧게 진행**합니다.
- 상세 보고보다 현재 결과물 확인, 개선 방향 결정, 다음 작업 선정에 집중합니다.

## 결과물 확인

- 현재 적용된 게임 연출은 전반적으로 나쁘지 않은 것으로 확인했습니다.
- 연출을 다시 크게 바꾸기보다는 핵심 플레이와 MVP 완성도를 다듬는 것을 우선합니다.

## 머지 방식 개선 방향

현재는 배송 버튼을 눌러 부품을 받고 오브젝트를 보드에 배치하는 흐름입니다. 이 방식보다 **Merge Gardens와 같은 일반적인 머지 게임 방식**을 적용하는 방향을 검토합니다.

- 배송 버튼 중심의 부품 수급 흐름은 재검토
- 보드 위 생성기 또는 일반적인 머지 장르의 오브젝트 생산 방식 참고
- 생성된 오브젝트를 바로 머지하며 플레이가 이어지는 익숙한 흐름 지향
- 구체적인 방식은 바로 구현하지 않고 문서 기준으로 먼저 정리한 뒤 Lab에서 비교 검증

## MVP 보완 목표

현재 결과물을 1차 MVP로 볼 수 있으나, 출시 가능한 플레이 구조로 보기에는 다음 부분이 덜 정리되어 있습니다.

1. 하트 소모·회복 규칙
2. 추후 보상형 광고를 연결할 지점
3. Day 달력과 대회일 표시
4. Day 진행에서 실제 레이스 진입까지의 연결
5. 일반적인 머지 방식으로의 플레이 흐름 개선

따라서 당분간 목표는 기능 확장보다 **MVP 완성도를 한 단계 더 다듬는 것**으로 정합니다.
