# MVP 범위

> 문서 상태: **출시 빌드 기준 정리 (기획 확정 대기)** · 갱신 2026-10-29 · 기준 코드 main `fb5f113`
> 8~9월 초안의 7×9 보드, T3 부품, Entry/Carbon/Flagship 완성차, `WORKSHOP`·`BUILD BIKE`·`DELIVER`·`RESET` 조작은 출시 빌드에 없어 지웠습니다(이전 내용은 git 기록).
> 이 문서는 **지금 출시 빌드에 들어 있는 것**을 적습니다. 수치와 규칙 대부분은 기획 확정 전 제안값이며, 확정할 곳은 마지막 절에 모았습니다.

## 검증할 핵심 루프

홈 PLAY → 작업대에서 부품 상자 열기(알바 체력 1) → 맞닿은 같은 부품 2개 합성 → 요구 레벨이 되면 자동 장착 → 4종이 모두 장착되면 납품·급여 → 주문 3건을 납품하면 하루 정산 → Garage(제작·강화·전시)와 도감 → 5일마다 대회

## 조작

작업대 화면 기준입니다.

| 조작 | 동작 |
|---|---|
| `부품 상자 열기` | 점선 칸(다음 입고 칸)에 부품 1개가 들어옵니다. 무료 상자가 있으면 먼저 쓰고, 없으면 체력 1을 씁니다 |
| 부품 누르기 → 맞닿은 같은 부품 누르기(또는 끌어다 겹치기) | 합성. 빈칸으로 옮기기는 안 됩니다 |
| `반품` | 고른 부품을 버립니다. 두 번 눌러 확인하며, 체력은 돌려주지 않습니다 |
| `되돌리기` | 직전 합성·반품·확정 상자 배치 1회. 상자를 열었거나 납품이 확정된 행동은 되돌릴 수 없습니다 |
| 합성 보너스 칸 | 확정 상자가 있으면 부품 종류와 빈칸을 골라 Lv.1을 놓습니다(체력 없음) |
| 알바 체력 표시 | 체력 카드(다음 회복·가득 참까지 남은 시간, 광고 충전)를 엽니다 |
| `← 홈` | Day를 일시정지하고 홈으로 갑니다. 다시 들어오면 같은 Day를 이어서 합니다 |

설정의 `저장 데이터 초기화`는 2단계 확인 뒤 보드·주문·코인·성장 기록을 모두 지웁니다.

## 제외

- Match-3 재료 수급
- 인앱 결제, 보상형 체력 충전 외의 광고
- LiveOps
- 서버와 로그인: 진행은 기기 저장소에 두고, 토스 익명 사용자 키로 저장 슬롯만 나눕니다. 서버가 없어서 생기는 제한은 [앱인토스 WebView 안내 6절 4단계](../development/APPS_IN_TOSS_WEBVIEW_GUIDE.md)에 적었습니다
- 레이스 A~D 비교안, 세계 코스 확장

제외 항목은 출시 뒤 별도 Issue로 다룹니다.

## 완료 조건

8~9월 초안의 완료 조건(Entry → Carbon → Flagship 주문 3건 납품)은 영업일 주문표로 바뀌어 쓰지 않습니다.

지금 빌드에서 핵심 루프 한 바퀴는 1챕터(1~5일차)입니다. 합성·상자·Lv.3·이월·도감 등록·제작·강화를 거쳐 5일차에 첫 대회에 나갑니다([레벨 디자인 3절](LEVEL_DESIGN.md)).

- **기획 확정 대기**: MVP 검증 완료 조건을 '1챕터 완주(첫 대회 참가)'로 둘지는 기획자가 정합니다.
- 출시 판정 기준은 [출시 계획 12절](../development/RELEASE_PLAN_2026_11.md)을 따릅니다.
