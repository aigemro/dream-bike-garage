# MVP 범위

## 검증할 핵심 루프

Workshop → 부품 생성 → 같은 부품 Merge → 완성차 제작 → 주문 완료 → Garage 수집

## 포함

- 7×9 Merge Board
- Workshop 1개
- 부품 3종: 프레임, 휠, 구동계
- 동일 아이템 2개 Merge
- 완성차 3단계: Entry, Carbon, Flagship
- 1차 브랜드 1개
- 주문 3개
- Garage 20칸

## 제외

- Match-3 재료 수급
- 스태미너
- 광고와 인앱 결제
- LiveOps
- 서버와 로그인

제외 항목은 핵심 Merge 재미가 검증된 뒤 별도 Issue로 다룹니다.
