# 메인 화면 구조 초안

> 문서 상태: **초안 (Draft)**  
> 출처: 2026-08-06 주간 회의 화이트보드 스케치

> [머지게임 시스템 설계서 10장 "화면 구성 초안"](MERGE_GAME_SYSTEM_DESIGN.md#10-화면-구성-초안)을
> 보강하는 문서입니다. 두 문서가 충돌하면 회의에서 확정한 뒤 설계서에 반영합니다.

## 1. 메인(주문 플레이) 화면 레이아웃

화이트보드 스케치를 기준으로 한 영역 배치입니다.

```text
┌────────────────────────────────────────────────┐
│ [이벤트 알림]      ( Stamina )      [획득 코인] │  ← 상단 바
│ [리더 순위 ①②]                        [Tour]   │
│                                                │
│   🚲  🚲  🚲  🚲  🚲                            │  ← 주문 자전거 슬롯
│  ┌──────────────────────────────┐              │
│  │                              │              │
│  │          머지 보드            │   조립도(?)  │  ← 플레이 영역
│  │                              │              │
│  └──────────────────────────────┘              │
│                                                │
│ ┌──────────┬────────────────────┬─────┐        │
│ │  알바생   │   Status  L-100    │  ♥  │        │  ← 하단 바
│ └──────────┴────────────────────┴─────┘        │
└────────────────────────────────────────────────┘
```

## 2. 영역별 요소

### 상단 바

| 요소 | 설명 | 비고 |
|---|---|---|
| Stamina (스태미너) | 플레이 자원 게이지. 상단 중앙 | 소모·회복 규칙 미확정 |
| 획득 코인 | 보유 재화 표시. 상단 우측 | |
| Tour 버튼 | 투어(보상 시스템) 화면 진입. 우측 | [투어 시스템](../meetings/2026-08-06-weekly-sync.md#3-투어tour--보상-시스템) 참고 |
| 이벤트 알림 | 진행 중 이벤트 표시. 좌측 | |
| 리더 순위 | 랭킹 표시 (①, ② 순위 목록 형태) | MVP 포함 여부 미확정 |

### 중앙 (플레이 영역)

| 요소 | 설명 | 비고 |
|---|---|---|
| 주문 자전거 슬롯 | 대기 중인 주문 자전거를 가로로 나열 (스케치 기준 5개 내외) | 기존 설계서의 "상단: 현재 주문" 영역에 해당 |
| 머지 보드 | 화면 중앙의 가장 큰 영역 | 설계서 기준 6×7 |
| 조립도 | 보드 우측 라벨 | **판독 불확실** — "조립도" 또는 "자립도"로 읽힘. 조립대(자전거 조립 영역) 표시로 추정, 확인 필요 |

### 하단 바 (3분할)

| 요소 | 설명 | 비고 |
|---|---|---|
| 알바생 (직급) | 현재 직급 표시. 좌측 | 직급: 알바생 → 견습공 → ? → Master |
| Status L-100 | 플레이어 상태·레벨 표시. 중앙 | 레벨 상한 100으로 추정, 확인 필요 |
| ♥ 아이콘 | 우측 아이콘 버튼 | **판독 불확실** — 하트 모양. 컬렉션 또는 상점 진입으로 추정, 확인 필요 |

## 3. 기존 설계서 대비 변경점

[설계서 10.1 주문 플레이 화면](MERGE_GAME_SYSTEM_DESIGN.md#101-주문-플레이-화면) 대비
이번 스케치에서 추가·변경된 요소입니다.

| 구분 | 항목 | 처리 |
|---|---|---|
| 추가 | 스태미너 게이지 | 소모 규칙 확정 후 설계서 반영 |
| 추가 | 투어 진입 버튼 | 투어 시스템 기획 확정 후 반영 |
| 추가 | 리더 순위(랭킹) | MVP 포함 여부 결정 필요 |
| 추가 | 이벤트 알림 | 이벤트(주문자 유형) 기획과 함께 반영 |
| 추가 | 직급·레벨 하단 바 | 직급 시스템 기획 확정 후 반영 |
| 유지 | 머지 보드 중앙 배치 | 설계서와 동일 |
| 확인 필요 | 온라인 부품 주문 버튼(프레임·휠셋·구동계·핸들바) | 스케치에 없음 — 배치 위치 결정 필요 |
| 확인 필요 | 조립대 위치 | 스케치의 "조립도(?)" 영역과 설계서의 "우측 또는 하단" 정합성 확인 |

## 4. 화면 간 이동 구조 (추정)

```text
메인(주문 플레이) 화면
 ├─ [Tour] → 투어 화면 (Day 1·2·3·… 진행, 사진 완성, Boss)
 ├─ [이벤트 알림] → 이벤트 상세
 ├─ [리더 순위] → 랭킹 화면
 └─ [♥ 아이콘] → 컬렉션 또는 상점 (미확정)
```

## 5. 확정이 필요한 항목

- [ ] "조립도(?)" 영역의 정확한 역할과 위치 (조립대 여부)
- [ ] 온라인 부품 주문 버튼의 배치
- [ ] 스태미너 게이지의 규칙과 표시 방식
- [ ] 하단 우측 아이콘의 기능
- [ ] 주문 슬롯 개수 (동시 주문 수 — 현재 MVP는 주문 1건)
- [ ] 리더 순위의 MVP 포함 여부
