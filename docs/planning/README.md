# Planning Sources

설계자가 작성한 기획 자료와 검토용 요약 문서를 관리하는 위치입니다.

## 관리 원칙

- PPT/PPTX로 기획서나 설계서를 작성하더라도 핵심 내용을 Markdown으로 함께 정리합니다.
- 원본 파일은 필요할 때만 보관하며, 협업과 변경 이력 관리는 Markdown 문서를 기준으로 합니다.
- 원본 기반 요약·아이디어·검토 자료는 `docs/planning`에 둡니다.
- 리뷰를 거쳐 확정된 게임 규칙은 `docs/game-design`에 반영합니다.
- 문서 변경 이유와 주요 결정은 Pull Request에 기록합니다.
- 대용량 이미지와 영상은 저장소 크기를 확인한 뒤 Git LFS 또는 별도 자산 저장소를 검토합니다.
