# 게임물 등급분류(GRAC) 접수 전 자료 보완

> 접수번호 **TG-OM-26-01350** · 신청서 종류 등급분류신청 · 신청 등급 전체이용가 · 진행상태 **접수전자료보완**
>
> 신청 자료 원본은 [GRAC 신청 자료](GRAC_SUBMISSION.md)를 따릅니다. 이 문서는 보완 요청 내용과 조치 내역, 재제출 순서를 기록합니다.

## 1. 보완 요청 내용 (2026-10-30 담당자 통화)

게임물관리위원회 등급분류 담당자가 전화로 알려 준 내용입니다. 시스템의 진행이력·상세 화면은 오류 페이지(`Error.aspx`)가 떠서 열리지 않았습니다.

### 1.1 제명 불일치

| 위치 | 표기 |
|---|---|
| 신청 제명 | 오늘부터 자전거 부자(Dream Bike Garage) |
| 동영상·설명서·실행 빌드 타이틀 | DREAM BIKE GARAGE (영문만) |
| 타이틀 부제 | 두리 자전거 공방 — 제명처럼 보임 |
| APK 앱 이름 | 자전거 부자 TEST |

- 한글·영문을 함께 적으려면 괄호 안은 **번역된 제목이나 읽히는 그대로의 표기**여야 합니다. '오늘부터 자전거 부자'와 'Dream Bike Garage'는 의미가 같지 않습니다.
- 신청 제명과 제출 자료(동영상·설명서·실행 빌드)에 보이는 게임 이름이 같아야 합니다.
- **자료 변경**은 바꾼 자료를 '자료 보완'으로 제출합니다.
- **제명 변경**은 (a) 철회 후 재신청하거나 (b) 제명 변경을 요청하는 **별도 문서**를 제출합니다.

### 1.2 설치 용량 10MB 초과

- 제출한 APK를 설치하면 앱 용량이 **약 12MB**로 10MB를 넘습니다(APK 파일 자체는 4.7MB).
- 10MB 미만과 10MB 이상은 **심의 수수료 구간이 다릅니다.**
- 담당자는 실제 서비스가 앱인토스 웹 형태라는 점도 확인했습니다(APK는 심의용으로 만든 것).
- 통화 결과: 용량을 맞춘 파일을 다시 올리기로 했고, 담당자가 제명 문제와 함께 보완 요청을 다시 보내기로 했습니다.

## 2. 조치 내역

### 2.1 제명: '오늘부터 자전거 부자' 하나로 통일

영문 제명을 빼고 앱인토스 한국어 앱 이름과 같은 한글 제명만 씁니다.

| 위치 | 변경 전 | 변경 후 |
|---|---|---|
| 타이틀 간판 (`src/game/release/title-loading-design.ts`) | DREAM BIKE / GARAGE / 두리 자전거 공방 | 오늘부터 / 자전거 부자 |
| 타이틀·설정 버전 표기 (`title-loading-design.ts`, `settings-design.ts`) | Dream Bike Garage · v0.1.0 | 오늘부터 자전거 부자 · v0.1.0 |
| 프로필 하단 표기 (`profile-design-prototype.ts`) | DREAM BIKE GARAGE · 오늘부터 자전거 부자 | 오늘부터 자전거 부자 |
| 웹 페이지 제목 (`index.html`) | Dream Bike Garage \| 오늘부터 자전거 부자 | 오늘부터 자전거 부자 |
| APK 앱 이름 (`capacitor.config.ts`, `strings.xml`) | 자전거 부자 TEST | 오늘부터 자전거 부자 |
| 게임물내용설명서 | 오늘부터 자전거 부자 (Dream Bike Garage) | 오늘부터 자전거 부자 |

- 작업대 상단의 '두리 자전거 공방 · 작업대'는 게임 속 **장소 이름**이라 그대로 둡니다. 타이틀에서는 제명으로 오해되지 않도록 뺐습니다.
- 게임 속 '드림 바이크'(주인공이 키우는 자전거)는 콘텐츠 용어라 그대로 둡니다.
- 저장소·앱 식별자(`dream-bike-garage`, `com.aigemro.dreambikegarage.test`)는 화면에 보이지 않으므로 바꾸지 않습니다.

### 2.2 설치 용량: APK 코드 축소·시작 화면 압축

보완 전 APK(압축 해제 기준 10.6MB)의 구성입니다.

| 구성 | 크기 | 조치 |
|---|---:|---|
| `classes.dex` (안드로이드 코드) | 7.1MB | R8 코드 축소. 축소가 꺼져 있어 쓰지 않는 라이브러리 코드까지 다 들어 있었음 |
| 시작 화면 PNG 6장 | 1.7MB | 256색 팔레트 PNG로 다시 저장 → 0.46MB (픽셀아트라 화질 차이 없음) |
| 게임 JS(Phaser 포함) | 1.5MB | 그대로 |
| 그 밖의 리소스·아이콘 | 약 0.3MB | 그대로 |

- `android/app/build.gradle` release 빌드: `minifyEnabled true`(R8 코드 축소) + `shrinkResources true`, `proguard-android-optimize.txt` 기본 규칙. Capacitor 플러그인 유지 규칙은 `@capacitor/android`가 함께 넣어 줍니다(`consumerProguardFiles`).
- `scripts/android-icons.mjs`: 아이콘·시작 화면을 다시 만들 때도 팔레트 압축이 적용되도록 단계를 추가했습니다.

**확인할 것**: 새 APK를 실기기에 설치하고 **설정 → 애플리케이션 → 오늘부터 자전거 부자 → 저장공간**의 앱 크기가 10MB 미만인지, 게임이 처음부터 끝까지 정상 동작하는지(뒤로가기·앱 전환·저장 포함) 확인합니다. 10MB를 넘으면 수수료 차액을 내는 방법을 담당자와 정합니다.

## 3. 재제출 순서

1. 이 브랜치를 main에 병합 → Actions **Android Test APK**가 새 APK를 만듭니다(Releases `android-test-latest`).
2. 실기기 설치 → 앱 크기 10MB 미만, 앱 이름 '오늘부터 자전거 부자', 정상 동작 확인.
3. **심의용 동영상 다시 촬영**: 타이틀 간판이 바뀌었으므로 [GRAC 신청 자료 3절](GRAC_SUBMISSION.md#3-심의용-동영상-촬영-순서) 순서로 새로 찍고 시간정보 표를 갱신합니다.
4. 보완 자료 제출 (GRAC 신청결과조회 → 해당 건 → 자료 보완)
   - 새 APK
   - 새 동영상 + 시간정보
   - 게임물내용설명서 보완본 (`dist-android/grac-supplement-2026-11/게임물내용설명서_오늘부터자전거부자_보완.docx`)
   - **제명 변경 요청서** (`dist-android/grac-supplement-2026-11/제명변경요청서_TG-OM-26-01350.docx`): 신청 제명에서 '(Dream Bike Garage)'를 빼 달라는 요청
5. 시스템 화면이 계속 오류로 열리지 않으면 교육정보센터(051-720-6888)나 담당자에게 이메일 제출이 가능한지 묻습니다.
6. 제출 후 진행상태가 바뀌었는지 확인하고 [#116](https://github.com/aigemro/dream-bike-garage/issues/116)에 기록합니다.
