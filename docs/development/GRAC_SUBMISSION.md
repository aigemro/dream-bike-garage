## 2. 게임물내용설명서 초안

### 2.1 게임 개요
자전거를 좋아하는 주인공 '두리'가 삼촌의 프로 자전거 대회를 보고, 자전거 공방에서 아르바이트를 하며 자신의 '드림 바이크'를 키우는 캐주얼 게임입니다. 손님 주문에 맞춰 부품을 합성해 자전거를 완성·납품하고, 받은 급여로 자전거를 제작·강화하며, 5일마다 열리는 동네 자전거 대회에 참가합니다. 모든 그림은 픽셀아트, 실존 브랜드·인물은 쓰지 않습니다.

### 2.2 플레이 방법
1. **첫 시작(프롤로그)**: 삼촌의 결승 레이스를 TV 중계로 보는 짧은 연출(건너뛰기 가능) 뒤 목표 카드를 보여 줍니다.
2. **작업대(핵심 플레이)**: 6×7 칸 작업대에서 부품 상자를 열면 부품(프레임·휠·구동계·핸들바)이 들어옵니다. 맞닿은 같은 종류·같은 레벨 부품 2개를 눌러 합치면 레벨이 오르고(Lv.1~4), 주문이 요구하는 레벨에 도달하면 자동으로 장착됩니다. 4종이 모두 장착되면 자전거가 완성되어 납품되고 게임 코인(급여)을 받습니다.
3. **하루 영업**: 주문 3건을 납품하면 하루가 끝나고 정산 화면을 봅니다. 시간 제한은 없습니다.
4. **알바 체력**: 부품 상자를 열 때 체력 1을 씁니다(최대 30, 실제 시간 10분마다 1 회복). 체력이 0이면 합성은 계속할 수 있고, 회복을 기다리거나 보상형 광고로 충전할 수 있습니다.
5. **수집·성장**: 납품한 자전거가 도감(24대)에 등록되고, 코인으로 자전거를 제작·강화·전시합니다.
6. **대회**: 5일마다 3,000m 자동 레이스(8명 출전)에 참가할 수 있습니다. 참가는 선택이며, 플레이어는 조작하지 않고 중계를 봅니다. 결과는 자전거 능력치로 정해집니다.

### 2.3 등급 요소별 내용

| 요소 | 내용 |
|---|---|
| 선정성 | 없음. 신체 노출·성적 표현 없음 |
| 폭력성 | 없음. 공격·부상·사망·혈흔 없음. 자전거 경주만 있고 충돌·넘어짐 연출 없음 |
| 공포 | 없음 |
| 언어 | 없음. 비속어·혐오 표현 없음. 대사는 가족 응원·일상 대화(예: "삼촌, 힘내!") |
| 약물 | 없음. 음주·흡연·약물 표현 없음 |
| 범죄 | 없음 |
| 사행성 | 아래 2.4. 현금·유료 재화가 없고 게임 결과를 현금·경품으로 바꿀 수 없음 |

### 2.4 사행성 관련 요소 설명
게임 안 재화는 **코인 한 가지**이며, 납품·대회로만 얻고 **현금으로 살 수 없고 현금·경품·다른 재화로 바꿀 수도 없습니다.** 이용자 간 거래 기능도 없습니다.

| 요소 | 동작 | 유료 여부 |
|---|---|---|
| 부품 상자 | 체력 1로 부품 1개를 받음. 아직 장착하지 않은 필요 부품이 나올 확률 85%, Lv.2로 나올 확률 기본 20%(자전거 강화로 최대 45%) | 무료(체력만 사용) |
| 합성 보너스 상자 | 합성 3회마다 무료 상자, 5회마다 부품 종류·칸을 고르는 확정 상자(Lv.1) | 무료 |
| 대회 | 참가비 500코인(게임 코인), 상금 1위 2,000 · 2위 1,200 · 3위 800 · 완주 200코인. 결과는 자전거 능력치로 정해지며 무작위 뽑기가 아님 | 게임 코인만 |
| 보상형 광고 | 체력 20 이하일 때 광고 1회를 끝까지 보면 체력 +10. 이용자가 원할 때만 보며 결과가 확정적(무작위 보상 아님) | 무료 |

- 인앱 결제, 유료 확률형 아이템, 현금성 보상은 없습니다.
- 앱 시작·로딩 중 광고는 없습니다.

### 2.5 이용자 정보·통신
- 토스 앱이 주는 익명 사용자 키(`User.getAnonymousKey`)로 기기 저장 슬롯을 나누고, 진행 데이터는 앱인토스 `Storage`(기기 안)에만 저장합니다. 자체 서버는 없습니다.
- 보상형 광고 충전 흐름의 이용 기록(제안 노출·시청·보상 여부 등)을 앱인토스 분석 기능(`Analytics.log`)으로 남깁니다. 이름·연락처 같은 개인 정보는 넣지 않습니다.
- 채팅·이용자 간 소통 기능은 없습니다.

## 3. 심의용 동영상 촬영 순서

**원칙**: 단순 실행 화면만으로는 부족하고, 등급 판단에 필요한 요소(확률 상자·대회 참가비/상금·보상형 광고·대사)가 모두 보여야 합니다. 동결 커밋으로 만든 빌드를 쓰고, 편집(컷)은 해도 되지만 화면 자체를 가공하지 않습니다.

**촬영 환경(권장)**: 휴대폰 토스 앱에서 동결 커밋의 앱인토스 테스트 번들을 실행하고 화면 녹화. 이때 광고는 공식 **테스트 광고**가 나옵니다. 실기기가 어려우면 웹(`?mockAd`)으로 찍되, 모의 광고 창이 실제 광고 대신 나온다고 내용설명서에 적습니다. 소리 켬, 진동 끔.

| # | 장면 | 보여 줄 것 | 목표 길이 | 관련 등급 요소 |
|---:|---|---|---:|---|
| 1 | 타이틀·로딩 | 앱 실행 → 로딩 → TAP TO START (광고 없음) | 0:20 | 광고 |
| 2 | 프롤로그 | 삼촌 레이스 중계·대사 전체(건너뛰지 않음) → 목표 카드 | 1:30 | 언어 |
| 3 | 홈 | 오늘 주문, 드림 바이크, NEXT GOAL, 대회 D-4 | 0:20 | — |
| 4 | 첫 플레이 안내 | 안내 6단계 | 0:40 | — |
| 5 | 작업대 기본 | 부품 상자 열기(체력 감소), 합성, 자동 장착, 납품·코인 획득 | 1:30 | 사행성(확률 상자) |
| 6 | 합성 보너스 | 합성 3회 무료 상자, 5회 확정 상자(부품·칸 고르기) | 0:40 | 사행성 |
| 7 | 하루 정산 | 주문 3건 완료 → 정산 봉투 → 급여·도감 등록 | 0:40 | — |
| 8 | 수집·성장 | 도감, 제작(코인 사용), 강화, 전시 | 1:00 | — |
| 9 | 체력 소진과 광고 | 체력 0 안내 카드 → 광고 버튼 → 광고 끝까지 시청 → 체력 +10. 광고 중간에 닫으면 보상 없음도 한 번 | 1:00 | 광고·사행성 |
| 10 | 대회일 | 5일차 정산의 참가 질문 → 참가비 500 차감 → 레이스 중계 → 결과·상금 수령 | 2:00 | 사행성(참가비·상금) |
| 11 | 설정 | 배경음악·효과음·진동 켜기/끄기 | 0:15 | — |

- 합계 약 10분. 5일차까지 실제로 플레이해 녹화한 뒤 편집합니다(5일차 = 주문 15건, 약 15~20분 플레이).
- GRAC 신청서의 '동영상편집물 시간정보'에는 편집본의 장면별 시작 시각을 위 표 순서대로 적습니다.

## 4. 실행 가능한 게임물

GRAC가 받는 형식(설치 파일·링크 등)을 신청 화면에서 확인한 뒤 아래 중 하나로 냅니다. 모두 **동결 태그 `screen-freeze-2026-10-29`에서 빌드**합니다.

| 형식 | 만드는 방법 | 비고 |
|---|---|---|
| 안드로이드 설치 파일(APK) | `git checkout screen-freeze-2026-10-29` → `npm run build:android` → [안드로이드 테스트 APK](ANDROID_TEST_APK.md) 절차 | 광고 없음(테스트 앱). 광고는 동영상으로 보여 줌 |
| 웹 링크 | https://aigemro.github.io/dream-bike-garage/?mockAd | main이 바뀌면 화면도 바뀌므로 **동결 뒤 main 병합을 멈추거나** APK를 우선 |
| 앱인토스 테스트 번들 | `npm run build:toss` (테스트 광고 ID) | 토스 앱 테스트 QR로만 실행되어 심의용으로는 부적합할 수 있음 |
