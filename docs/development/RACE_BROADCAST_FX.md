# 레이스 중계 이펙트 (레이싱 게임 연출 문법 적용)

> 작성일 2026-10-23 · 이슈 [#108](https://github.com/aigemro/dream-bike-garage/issues/108) · 규칙 [`race-fx.ts`](../../src/game/release/race-fx.ts) · 그리기 [`race-fx-layer.ts`](../../src/game/release/race-fx-layer.ts) · 검증 [`tests/race-fx.test.ts`](../../tests/race-fx.test.ts)

레이스 중계 화면(`RaceBroadcastScene`, 대회일 레이스와 프롤로그 공용)에 **레이서 자체에서 나오는 효과**(출발·먼지·스퍼트·잔상)와 **코스 위 정보 오브젝트**(남은 거리 표지판·출발선), **이벤트 연출**(집중선·순위 변동·골 컨페티)을 더한 내용을 정리합니다. 국면별 카메라·속도선·시네마 바·역전 슬로모션·사진 판정은 [RACE_RIDER_MOTION.md](RACE_RIDER_MOTION.md) 9절과 [PROLOGUE.md](../game-design/PROLOGUE.md) 4.1절이 기준이며, 이 문서는 그 위에 얹힌 이펙트만 다룹니다.

## 1. 참고 범위

우마무스메·마리오 카트·소닉 같은 레이싱 게임과 만화 컷인의 **연출 문법만** 참고했습니다. 캐릭터·UI 구성·고유 명칭·음성·화면 자산은 쓰지 않고, 모두 UI 스타일 가이드 팔레트(INK·CREAM·PAPER·GOLD·RED·GREEN·SKY)와 2px 픽셀 격자 안에서 다시 그립니다.

| 연출 | 참고 문법 | 이 게임에서 |
|---|---|---|
| 출발 신호등 | 마리오 카트·F1 출발 신호 | 카운트다운 3·2·1에 빨간 램프가 하나씩 켜지고 `GO!`에 전부 초록 |
| 출발 대시 | 마리오 카트 로켓 스타트 | `GO!` 순간 모든 레이서 뒷바퀴에서 먼지 뭉치 10개 + 짧은 진동 |
| 주행 먼지·바람 줄기 | 레이싱 게임 타이어 먼지·스피드 라인 | 자세·바퀴 티어별 입자(아래 3절) |
| 스킬 발동 콜아웃 | 우마무스메 스킬 발동 팝업 | 자세 전환 순간 레이서 위로 칩이 떠오르고 레이서가 80ms 번쩍임 |
| 스퍼트 오라 | 우마무스메 스퍼트·고유 스킬 오라 | 마지막 600m 금색 → 마지막 150m 빨강 + 스파클, 꼬리가 뒤로 흐르는 디더 타원 |
| 잔상 | 소닉·우마무스메 스퍼트 잔상 | 스탠딩 스프린트 실루엣이 지면 속도로 뒤로 흘러가며 사라짐 |
| 남은 거리 표지판·출발선 | 우마무스메 잔여 거리 표시·육상 중계 | 1km 단위·600m·300m·150m 표지판과 `START` 라인 |
| 집중선 | 만화 컷인·격투 게임 초필살기 | 역전 컷인·사진 판정 정지에 화면 가장자리에서 중앙으로 모이는 잉크 선 |
| 순위 변동 팝업 | 레이싱 게임 포지션 체인지 | HUD 순위 옆 `▲ 3위`(초록) / `▼ 5위`(빨강) |
| 골 컨페티 | 우마무스메 GOAL·마리오 카트 결승 | 포디움(3위 안) 결승 통과에 결승 마커 위 컨페티, 1위가 가장 많음 |
| 땀방울 | 우마무스메 스퍼트 표정 | 오르막·스퍼트에서 주인공 머리 옆 하늘색 방울 |

## 2. 구조

```
race-climax.ts (막판 강도·샷)      race-rider-motion.ts (자세·바퀴 티어)
            │                              │
            └──────► race-fx.ts (순수 규칙: 언제·무엇을·얼마나) ◄──────┘
                              │
                              ▼
                     race-fx-layer.ts (Phaser: 입자·칩·잔상·표지판·집중선)
                              │
         RaceBroadcastScene가 만들고 매 프레임 update()에 레이서·주인공·막판 강도를 넘김
```

- `race-fx.ts`는 Phaser를 모르는 순수 모듈입니다(`tests/race-rider-purity.test.ts`가 강제). 콜아웃 문구·입자 간격·오라·잔상·표지판 위치·집중선·순위 변동·컨페티 수·땀 간격·모션 축소 예산을 수치 규칙으로 두고 `tests/race-fx.test.ts`가 지킵니다.
- `race-fx-layer.ts`는 그 값을 읽어 그리기만 합니다. 입자는 파티클 에미터 5개(먼지·바람 줄기·스파클·땀·컨페티)로 한 번에 그리고, 텍스처는 흰 픽셀 캔버스라 `tint`로 색을 정합니다.
- `RaceBroadcastScene`(race-cinematic-broadcast.ts)이 중계를 만들 때 레이어를 함께 만들고(`startBroadcast`), 재생 루프에서 `updateCourseMarks`·`update`를, 카운트다운·역전 컷인·사진 판정·순위 갱신에서 이벤트 메서드를 부릅니다. 대회일 레이스와 프롤로그는 같은 씬을 쓰므로 연출도 같습니다.
- 레이서 뷰(`race-rider-view.ts`)에 잔상용 실루엣 복제(`cloneSilhouette`), 번쩍임(`setFlash`), 뒷바퀴 접지점·머리 위치(`rearContactOffset`·`headOffset`)를 더했습니다.

## 3. 규칙 요약

| 연출 | 조건 | 수치 |
|---|---|---|
| 출발 신호등 | 카운트다운이 있는 중계(프롤로그는 없음) | 램프 3개, 단계가 램프보다 많으면 마지막 3단계에서 켜짐(`startLampsAt`) |
| 콜아웃 | 자세 전환: `climb` `클라이밍!`(초록) · `tuck` `에어로 턱!`(하늘) · 스퍼트 후반(85%~) `sprint` `라스트 스퍼트!`(빨강). 착좌 복귀·출발 직후 스탠딩 스타트·완주 후 없음 | 주인공은 전부, 다른 레이서는 라스트 스퍼트만(화면 안에 있을 때). 떠오름 180ms → 머무름 900ms → 사라짐 300ms |
| 먼지 | `sprint` 120ms · `climb` 220ms 간격(crisp 티어 제외) | 뒷바퀴 접지점, 뒤·위로 튀어 가라앉음 |
| 바람 줄기 | `blur` 티어(내리막·x2 이상), 완주 코스팅은 blur에서만 | 110ms(코스팅 150ms) 간격 |
| 오라 | 마지막 600m(강도 1) 금색 알파 0.32·맥박 520ms → 마지막 150m(강도 2) 빨강 알파 0.42·맥박 360ms + 스파클 120ms 간격. 완주 후 꺼짐 | 80×36셀 꼬리 타원, 가산 혼합, 주인공 몸통(앵커 +2, −44) 기준 |
| 잔상 | 스탠딩 스프린트 + 마지막 600m: 3장 150ms 간격 450ms 수명 → 마지막 150m: 4장 110ms 간격 440ms 수명. 크림 실루엣 | 시작 알파 0.6, `(1−t)^0.7`로 감쇠, 지면 속도로 뒤로 이동, 주인공 깊이 바로 아래 |
| 표지판 | 코스 길이보다 짧은 1km 단위 + 600m·300m·150m. 600m 안쪽은 빨강 | 결승선 마커와 같은 월드 거리 계산(`poleScreenX`) |
| 집중선 | 역전 컷인 28개·900ms·알파 0.5 / 사진 판정 20개·520ms·알파 0.35 | 70ms마다 다시 그려 깜빡임, 중앙 70~110px 비움 |
| 순위 변동 | 진행률 5% 이후, 새 순위가 500ms 유지될 때(접전 깜빡임 방지) | HUD 순위 옆 (318, 30) |
| 컨페티 | 주인공 결승 통과 순간 1위 36 · 2위 20 · 3위 12 | 결승 마커 위, 실제 시간으로 떨어짐(정지 화면 위에서도) |
| 땀방울 | 주인공 `climb` 700ms · `sprint` 450ms | 머리 옆 |

시간 규칙: 입자·잔상·오라 스파클·콜아웃 판정은 **경기 재생 시간**(사용자 배속 × 연출 배속 `timeScale`)을 따라 역전 슬로모션·사진 판정 정지에서 함께 느려지고 멈춥니다. 콜아웃 칩·집중선·신호등·순위 팝업·컨페티는 화면 연출이라 **실제 시간**으로 흐릅니다.

깊이: 표지판·출발선 4(결승 마커와 같음) → 오라 9.8 → 레이서 10~10.8(잔상은 주인공 −0.01) → 먼지·바람 줄기 11 → 스파클·땀·콜아웃(레이서 컨테이너 자식) 17 → 컨페티 18 → HUD 20+ → 순위 팝업 26 → 집중선 51.5(컷인 슬랩 52 아래) → 신호등 58.

모션 축소(`prefers-reduced-motion: reduce`)에서는 `fxBudgetFor`가 입자·잔상·집중선·오라를 끄고 신호등·표지판·콜아웃·순위 변동만 남깁니다.

## 4. 효과음

대회일 레이스에도 프롤로그와 같은 `onSfx` 훅을 연결했습니다(통합 컨트롤러 `ReleaseAudio`). 전용 효과음은 아직 없고 기존 효과음을 임시로 씁니다: 카운트다운 `tap`, 출발 `start`, 마지막 600m `parcel`, 역전 컷인 `merge`, 사진 판정 `complete`, 보상 수령 `reward`. 전용 효과음은 [ASSET_WORKFLOW.md](ASSET_WORKFLOW.md) 운영에서 정합니다.

## 5. 확인 방법

- `npm run dev` 뒤 `/dream-bike-garage/dev/race.html?seed=<시드>`에서 바로 볼 수 있습니다(저장 미연결). `window.__raceGame.scene.scenes[0].playMs`를 틱×600으로 바꾸면 국면을 건너뛸 수 있는데, 큰 점프 직후 약 1초는 바퀴 속도 스파이크로 잔상이 멀리 밀려나므로 2초쯤 기다린 뒤 봅니다.
- 역전 컷인·사진 판정·컨페티를 한 번에 보려면 플레이어가 스퍼트에서 역전 우승하는 시드를 씁니다(기본 스탯 기준 `seed=5`: 96.4% 지점 역전, 0.1초 차 사진 판정 / `seed=28`: 77.2% 역전, 0.3초 차).
- 프롤로그(`/dream-bike-garage/dev/prologue.html`)는 카운트다운이 없어 신호등·출발 대시가 없고, 나머지 연출은 삼촌을 주인공으로 같게 나옵니다.
